XCutors is a curated collection of popular Roblox script executors for Windows. It bundles multiple executors—Volt, Synapse Z, Potassium, and Wave—along with a universal loader called xcutorsLoader for easy management.

### Which executors are included?

XCutors includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader that lets you manage and switch between them from a single interface.

### Is XCutors free to use?

Yes, XCutors is completely free to download and use. All included executors are open-source or community-maintained versions.

### What operating systems are supported?

XCutors currently supports Windows 10 (version 1903 and later) and Windows 11. macOS and Linux are not supported at this time.

### How do I update the executors?

xcutorsLoader includes a built-in update checker. When you launch the loader, it will automatically notify you if newer versions of any included executor are available.

### Can I add my own Lua scripts?

Absolutely. You can paste scripts directly into the built-in editor, load .lua files from disk, or import scripts from the integrated script hub.

### Why is my anticomponent flagging the download?

Script executors often trigger false positives in anticomponent software because they inject code into other processes. You may need to add an exclusion for the XCutors folder in your anticomponent settings.

### Where can I find scripts to use?

XCutors includes a built-in script hub with popular community-contributed scripts. You can also find scripts on community forums and script-sharing websites.

### Do I need to disable my firewall?

In most cases, no. However, if you experience connection issues, you may need to allow xcutorsLoader.exe through your Windows Firewall settings.

### How do I report bugs or request features?

Please open an issue on the GitHub repository's Issues page. Include a detailed description, steps to reproduce, and your system information for fastest resolution.
